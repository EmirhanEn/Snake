# Meyve Bahçesi Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task by task. The user authorized native implementation in this session.

**Goal:** Deliver a playable cartoon C++ Snake game as a Windows EXE.

**Architecture:** Separate deterministic rules, generated audio and raylib presentation. Render at 1280×800 with letterboxing; run fixed simulation ticks with interpolated rendering.

**Tech Stack:** C++17, raylib 5.5, MSVC, CMake/CTest.

**Spec:** docs/superpowers/specs/2026-10-20-orchard-design.md

## Global Constraints

- Cartoon art; Turkish copy; three modes; original music and effects.
- No Python required for the delivered game.
- Save failures and missing audio devices cannot prevent play.
- 24×18 board, two buffered turns; all modes retain self collisions.

## Review Focus

- Two fast turns before a tick must not permit a reversal.
- Wrapping must not draw a stripe across the board.
- Full board must become a win, without random-selection failure.
- Pausing, focus loss and window resizing must not advance simulation.
- Non-ASCII working directories must not affect launch or persistence.

### Task 1: Rules and build

Files: `CMakeLists.txt`, `build.ps1`, `src/game.hpp`, `src/game.cpp`, `tests/game_tests.cpp`.
Interface: `Game::reset(Mode,Difficulty)`, `turn(Direction)`, `step() -> Event`, public read-only-by-convention round state.

- [ ] Write behavior tests and run against initial no-op implementations; observe failing assertions.
- [ ] Implement collisions, queue, modes, growth, full-board success and food selection.
- [ ] Compile and run the complete rules suite.

### Task 2: Original sound

Files: `src/audio.hpp`, `src/audio.cpp`.
Interface: `Audio::init()`, `update(float)`, `effect(Cue)`, `setMusic(float)`, `setEffects(float)`, `shutdown()`.

- [ ] Synthesize an original 16-bar looping tune with plucked melody, soft bass, percussion and stereo space.
- [ ] Add non-blocking pick-up, UI, countdown, lose and win sounds; gracefully handle unavailable audio.
- [ ] Verify PCM values, duration and peak levels as part of smoke diagnostics.

### Task 3: Cartoon presentation and delivery

- [ ] Implement menu, modes, difficulties, settings, gameplay, pause and results.

- [ ] Build release, run CTest and deterministic UI smoke sequence; inspect screenshots and fix issues.
- [ ] Package a ready-to-run EXE with required licenses and launch instructions.
